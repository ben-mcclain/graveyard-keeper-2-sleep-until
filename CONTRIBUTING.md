# Contributing

Bug reports, fixes, and documentation improvements are welcome.

- Include reproducible steps and relevant log excerpts in an issue. Describe your game/BepInEx versions and other mods.
- Keep personal details out of logs. Do not commit game binaries, assets, save files, decompiled game code, or credentials.
- Build against your own game installation using the instructions in the README.
- For changes to scheduling or sleep hooks, run the test suite and describe any in-game checks you performed. Keep untested behavior clearly identified.
- Preserve vanilla behavior for Normal and unrelated scripted sleeps. Keep changes to save handling narrow and reviewable.

Contributions to the original mod code are provided under this repository's MIT License.
