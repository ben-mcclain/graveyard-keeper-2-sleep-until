# Changelog

## 0.1.0 - 2026-10-18

Initial public release, reported working in-game.

- Bed menu with Normal, next morning, all six weekdays, and Cancel.
- Scheduled sleep at full energy, with a preview of the wait.
- F8 / Wake now for early waking.
- Native accelerated world simulation and wake/save path.
- Modal menu with mouse and mapped keyboard/controller inputs.
- Calendar test suite and static checks of game integration points.

The release DLL is byte-for-byte identical to the first privately tested build. Public documentation and developer test-path configuration have been improved. Broader platform, controller, and mod compatibility testing remains open.
